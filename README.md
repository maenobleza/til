# Today I Learned

Short notes on things I learn while working through Linux, Docker and Ansible labs on a test machine. The plan is in [LABS.md](LABS.md); a note is added when a lab is done.

This repository is new. `templates/example-note.md` shows the format and is not one of the notes.

Categories: `linux/` · `docker/` · `cloudflare/` · `networking/` · `ansible/`

## How I write these
One file per note, dated filename, under 200 words, with the command or config that actually worked. If I was wrong somewhere, I fix the note and keep the history.

## Rebuild the index

Run `bash scripts/index.sh` from any working directory. The script indexes Markdown
files in the categories above, newest filename first, and replaces only the
generated section below the marker. Keep handwritten content above that marker.
Filenames may contain spaces or URL punctuation. Bash 3.2+ and standard Unix tools
are sufficient; GNU-specific `sed -i` is not required.

To run the regression checks with Python 3:

```sh
python3 -m unittest discover -s tests -v
```

The tests use temporary fixture repositories and do not rewrite these notes.
